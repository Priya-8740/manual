### **1. Open project**

```
cd C:\Users\acer\Downloads\demo
```

### **2. Check Java**

```
java -version
```

### **3. Check Maven**

```
.\mvnw.cmd -version
```

### **4. Build project**

```
.\mvnw.cmd clean package -DskipTests
```

### **5. Run Spring Boot**

```
.\mvnw.cmd spring-boot:run
```

### **6. Check port 8080**

```
netstat -ano | findstr :8080
```

### **7. Connect MySQL**

```
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p
```

### **8. MySQL commands**

```
SHOW DATABASES;
```

```

```

```

```

### **9. Insert 3 SIM records**

```
INSERT INTO SimDetails (serviceNumber, simNumber, simStatus)
VALUES
('9876543211', 'SIM1002', 'active'),
('9876543212', 'SIM1003', 'inactive'),
('9876543213', 'SIM1004', 'active');
```

### **10. Verify records**

```
SELECT * FROM SimDetails;
```
